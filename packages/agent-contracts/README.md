# Emmy and specialist-agent contracts

Emmy is the only visible AI in the Averon ecosystem. Specialist agents are internal workers; users do not select or chat with them directly. Emmy will eventually resolve workspace context, classify intent, create structured tasks, request approval where required, delegate execution, validate results, and produce a final response.

This package defines contracts only. It does not execute agents or call AI providers. Altrex Code will later implement or power coding-related tasks. Agent execution and full Emmy orchestration belong to a later migration phase.
